## Behavior

- **Lifecycle**: `connect` runs MCP initialize with a timeout. The negotiated version is captured
  from the SDK transport hook and exposed as `capabilities.protocolVersion`. A failed connect closes
  the client. `close()` closes the client, and for stdio the SDK terminates the subprocess.
- **Discovery**:
  - `listTools` maps one page (cursor pass-through). `catalog.all()` walks all pages with a page
    cap (default 20), cursor-loop detection and duplicate-name rejection.
  - Input schemas must be object schemas.
  - `_meta`, icons and unknown annotation keys are dropped.
- **Definition version** = SHA-256 fingerprint of everything the model or policy sees (name, title,
  description, input/output schema, the four annotation hints). Any change gives a new version, which
  invalidates approvals bound to the old one.
- **Invalidation**: `tools/list_changed` or a disconnect drops the cached snapshot. A load that races
  an invalidation is reloaded (at most 3 times), never cached stale.
- **Namespaced IDs**: `namespaceTools('inv', defs)` produces `inv__lookup`. Names needing
  sanitizing or truncation get `_<8 hex>` derived from server ID + original name, so the alias is
  stable across definition changes; any detected collision is rejected. The alias maps back to the
  exact `McpToolRef`; it grants nothing.
- **callTool** rechecks before dispatch:
  - owner scope + connection (`permission`), liveness (`connection_unavailable`), abort, deadline;
  - capability, request validity;
  - that the exact definition version is still advertised (`not_found`).
  It then rechecks liveness/abort after the catalog await. All of these return `error`, never
  `unknown`, because nothing was sent.
- **After dispatch**: `client.request('tools/call')` is used instead of `client.callTool`.
  - The SDK's `callTool` validates output *after* execution and throws the same `InvalidParams`
    code as a server refusal, which would turn an executed call into a false "not applied".
  - A JSON-RPC error response is a server refusal: `InvalidParams` maps to `invalid_value` and
    `MethodNotFound` to `unsupported`, both as `error`.
  - A timeout, abort, closed connection or other local fault is `unknown`.
  - Results go through the P02-04 normalizer (`isError` → `error`; malformed → `unknown`).
  - Raw error text is never forwarded.
- **Transports**:
  - Stdio passes only the SDK's minimal default environment plus explicit entries, and stderr is
    ignored.
  - HTTP requires `https` except loopback, rejects credentials in the URL, and uses
    `redirect: 'error'`.
  - Headers/env carry credentials only once P05-03 resolves them through the credential port.

## Owner validation before review

- `node --import tsx --test tests/contract/mcp-client/*.test.ts`: PASS, 13 tests.
- They use a real stdio subprocess and an in-process Streamable HTTP server on an ephemeral
  loopback port, both from `tests/support/mcp/fixture-server.ts` (SDK low-level `Server`,
  7 tools, page size 2).
- Covered:
  - protocol `2025-11-25` negotiated; 4-page discovery; stable versions after invalidation;
  - success / `isError` / server-refused args are distinct and never unknown;
  - stale version, foreign scope and pre-aborted calls are refused, with the server call log
    proving no dispatch;
  - timeout and mid-call abort are `unknown`;
  - `list_changed`: the new tool appears, the changed tool gets a new version, the old version
    is refused;
  - a crash mid-call is `unknown`, then the session closes, the catalog is invalidated and
    later calls are `connection_unavailable`;
  - close kills the subprocess (pid checked);
  - resources/prompts read; a tools-only server reports resources `unsupported` while tools work;
  - HTTP end-to-end call; endpoint rules;
  - definition-version sensitivity; alias stability, collisions and provider-safety.
- Mutation check: six breakages were each caught, then restored and verified with `cmp`:
  - unknown reported as error;
  - stale definitions not checked;
  - `list_changed` ignored;
  - server refusal treated as unknown;
  - owner check bypassed;
  - plain http allowed.
- `npm.cmd run check`: PASS for typecheck, lint, architecture and docs (0 violations), with
  162 unit and 87 contract tests. `npm.cmd run build`: PASS.
