## Behavior preserved and intentional changes

### S02 emptiness (copy)

Preserved exactly: null, undefined, blank string and `[]` are empty; `0`, `false`, `NaN` and `{}`
are not. `readResultErrorField` was not adopted, per the manifest. A test documents that a
successful read with `[]` data is not an empty value at the result level.

### S03 current time (adaptation)

- The instant (epoch ms), IANA time zone and BCP 47 locale are all required inputs.
  There is no `new Date()`, no default zone and no default locale.
- The zone label is derived by ICU instead of being hardcoded as `WIB`. For example,
  Asia/Makassar gives WITA, Asia/Jayapura gives WIT and New York gives EDT/EST.
- Output is a single locale-native ICU sentence. For id-ID/Asia/Jakarta it reads
  `Selasa, 4 Agustus 2026 pukul 14.35 WIB`; legacy produced
  `Selasa, 4 Agustus 2026, pukul 14.35 WIB` (the only difference is the comma before
  `pukul`). The word "pukul" is no longer hardcoded, so other locales read naturally.
- Invalid instant, zone or locale throws a `RangeError` instead of formatting garbage.
- Output depends on Node's ICU data (Node 22.16.0, ICU 77.1 here). Tests therefore assert
  the weekday/date/time/label parts rather than byte-exact strings, so they survive an ICU
  punctuation change.

### S04 token estimator (extraction)

- Kept: the weighting of `TokenEstimator.estimate` (char/word blend, Latin 0.5 vs other 0.7,
  minimum 1, defaults 3.5 chars/token and 1.3 tokens/word, UTF-16 length).
- Dropped/deferred: the static class, model presets, `estimateMessages`, `estimateDetailed`
  and message framing overhead, per the manifest.
- Changed: the result is `{ tokens, approximate: true }` (frozen), so callers cannot mistake it
  for provider usage.
- Changed: invalid factors (0, negative, NaN, Infinity) throw. Legacy `||` silently
  fell back to the defaults.
- Changed: whitespace-only text counts 0 words and is estimated as 1 token. Legacy split
  `"   "` into one phantom word and returned 2.
