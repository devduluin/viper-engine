## Safety and compatibility decisions

Mutation requests are sent once. Stable host IDs/keys plus server receipts, not transport retries,
control duplicates. Read abort/break cancels stream resources without durable cancellation.
Opaque cursor advances only for complete validated durable frames, after caller resumes yield.
Consumer storage must atomically apply/dedup and checkpoint its own view for crash safety.
Eight cumulative reconnects default, exponential capped backoff. Expired/gap/unknown event causes
snapshot replacement; historical audit consumers cannot recover pruned events through this helper.

Request schemas unchanged; response decoder relaxes optional fields only. Same-role assistant
variants keep known field validation while accepting future fields. Invalid version/type fails.
Origin-only URLs, header tokens, redirect error, bounded UTF8 bytes and sanitized error code envelope.
Optional usage is additive within v1. Unknown aggregate fields stay null; source mixed where needed.
No billing estimate. modelCalls counts audit attempts, including unavailable/pending failures.
