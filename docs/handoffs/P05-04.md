## Delivered

- `src/bootstrap/engine.ts` composes the existing durable driver/journal with actual model
  binding, PostgreSQL MCP directory, session pool, pooled gateway, discovery/aliases,
  production JSON Schema validator and mandatory host policy. No replacement loop.
- Small composition components: engine-types/config/lifecycle, configured-model and mcp-tools.
  Root exports expose bootstrap factory/config/types, not adapter implementation barrels.
- `src/adapters/mcp/client/pooled-gateway.ts` reauthorizes each scope/connection operation and
  forwards tool/resource/prompt calls. Inputs/options are captured before awaits. Timing is
  bounded; post-handoff failure stays conservative unknown. No tool retry.
- `src/adapters/validation/tool-schema.ts` provides synchronous isolated bounded compilation;
  strict schema validation without remote loading, coercion/defaults/removal or raw errors.
- Model result projection preserves MCP evidence. OpenAI Chat Completions tool images are
  attached after the entire result batch; unsupported audio terminates with model_failure
  before another provider request, retaining the completed tool in durable history.
- Actual SDK scripted-fetch + actual local MCP HTTP/stdio + isolated PostgreSQL E2E tests.
  Fixtures are opt-in: original default fixture catalogs and evaluation dataset unchanged.
