## Grading and limits

Ten fixtures include read chain, empty, exact accepted/declined write, actual error/unknown, schema,
input/cancel and final. Persisted ledger/usage/effects and404 scope/refetch/idempotency/no-replay
checks determine correctness. Declined/invalid operations remain unexecuted even when the dialogue
completes; exact refusal code and zero effects are required. No keyword self-judgment success claim.

Cold/warm are explicitly local adapter/engine lifecycle states; raw catalog traffic reveals actual
behavior. Each trial has a new run/conversation and reset business effects. Setup/migrations excluded
from latency; automatic fixture input/approval included. Quantiles nearest-rank, n explicit. SDK usage
values are scripted, port usage unknown, costs null. Semantic quality/real billing/V4/Hermes unmeasured.

Missing/duplicate trials/suites, missing critical files, failed/skipped/cancelled/malformed TAP,
cleanup failures and source drift fail the report. Source snapshots exclude hidden/env/artifact
files and refuse symlinks/escape. Child env allowlist forwards explicit test DB only in PG mode.
Raw synthetic request bodies omit headers/credentials; do not reuse for live/private data blindly.
