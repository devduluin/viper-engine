## Guarantees and limits

Input text estimate + output reserve + framing reserve and internal ModelRequest byte limit checked
before model-start/gateway. Full history validated first. Complete turns/reversed results preserved;
current run and unknown outcome turn cannot be trimmed. Oversized required context stops with
context_input_limit/BUDGET_EXCEEDED before a model or new tool call; full ledger/history remain.

Recency-first contiguous suffix, not semantic search. Prefix summary contains bounded incomplete
extracts from both ends, never a verified-fact claim or new system authority. No summarizer model.
Snapshot of original policy and owner/run/conversation-bound source digest/excerpt persists under
existing lease/CAS journal with model audit. Resume verifies source before any accepted write;
latest clarification cannot move the original current-run anchor. Original call IDs/outcomes/budgets
remain authoritative even when omitted from model view. Cancel can remove damaged context view.

No new migration/table/dependency. Existing runtime_checkpoints.state v1 accepts new optional fields;
older checkpoints still load, new host policy is adopted once if absent. Once pinned, budget changes
apply to new runs. API v1 gains optional report/schema only; original requests/events unchanged.

No physical history compaction; default full-checkpoint reader cap stays 10000 messages. Media tokens
and provider framing remain unpriced estimates. Current run may hit the bound rather than compress
active work. Internal JSON bytes differ from provider SDK wire bytes. Vector/recall/notes await P07-02.
