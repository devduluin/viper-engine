## Context contract and boundaries

- Application supplies authenticated scope, authorized catalog aliases, instructions and a
  storage-loaded ScopedHistory. A typed envelope does not authenticate client-supplied messages.
- Scope actor/app/tenant and conversation must match. Instructions must be system messages;
  persisted history cannot add system messages. API ingress role restrictions remain application work.
- Snapshot clones/freezes message content, arguments and JSON schemas. Only model-facing tool
  name/schema/description are projected; arbitrary host fields are not spread into the catalog.
- Duplicate IDs, orphan/duplicate/pending results, unsupported model features and expired
  deadlines reject before generation. Out-of-order parallel results remain valid when complete.
- Tool output remains tool data, including JSON containing `role`, `approved` or budget fields.
  Error/unknown outcomes are retained; a successful empty read remains valid.
- No implicit history truncation/compression. P07-01 owns context selection/compression.
- Estimate includes serialized text, JSON arguments/data and schemas; media bodies are omitted.
  `approximate`, `hasUnpricedMedia` and `excludesProviderFraming` prevent treating it as actual usage
  or a complete media-aware budget. P03-03 owns limits; provider usage remains authoritative.

## Offline fixtures and reuse

- Fake gateway reuses `evals/support/fake-mcp.mjs`, unchanged P00 catalog/scenarios and P02-04
  normalization. No copied domain tool implementation or new registry.
- The canned service validates input schemas and selects exact argument fixtures. It is not a
  protocol transport or production execution authorization mechanism.
- Bridge checks owner/connection/capabilities/version/abort/deadline and rechecks after the
  catalog await. Tools-only capability and unsupported pagination fail explicitly.
- Resources/prompts stay separate application-selected MCP operations. P00 singleton prompt
  content is normalized to the port's content array.
- Script exhaustion and expectation mismatch fail instead of fabricating a final response.
  No provider SDK, credentials, network calls or legacy imports are used.
- Text estimation consumes P02-03 with its recorded provenance; no additional legacy source
  copied. Existing dataset hashes/historical P00 manifest were not regenerated.
