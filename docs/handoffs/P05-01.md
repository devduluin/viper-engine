## Behavior

- **Request**:
  - Leading system messages become the top-level `system`.
  - User content maps to text and image blocks (base64 or URL); JSON blocks are sent as canonical
    text; audio is not offered.
  - Assistant tool calls become `tool_use`.
  - All tool results of a turn go in **one** user message (`is_error` for `error` and `unknown`).
  - Tools map to `input_schema`. `responseSchema` maps to `output_config.format`.
- **Model defaults**: `claude-opus-5-5`, adaptive thinking (always on for current models),
  `output_config.effort` from config (default `medium`, smoke uses `low`).
- **Preserved thinking**: Anthropic requires earlier thinking blocks to be sent back unchanged.
  - The engine's provider-neutral history cannot hold them, so the adapter remembers each turn's raw
    content blocks keyed by owner/conversation/run/model/tools/schema/history and the normalized
    assistant turn, and replays them verbatim only within that binding.
  - Every request sets `thinking.block_binding.prefix_mismatch_behavior: "drop_block"` (beta
    `thinking-binding-controls-2026-08-01`). A cache miss, a restart or a mismatch then only drops
    old reasoning and never fails the turn.
  - The cache is a deeply immutable in-memory LRU (1000 turns, 16 MiB). A durable variant belongs to P04-04
    checkpoints if cross-process reasoning continuity is wanted.
- **Refusal fallback**: `fallbacks: "default"` (beta `server-side-fallback-2026-07-01`) is sent
  only for models documented to accept it (Fable 5.2/5.1, Opus 5.5/5, Sonnet 5.5) and can be
  turned off with `VIPER_MODEL_FALLBACKS=false`.
- **Decisions and failures**:
  - Any `tool_use` makes a `tool_calls` decision, keeping same-turn text as content. Text alone
    makes `final`.
  - `refusal` → `permission` (generic safe message). `max_tokens` → `output_limit`, and a truncated tool
    input is never executable. Context overflow → `unsupported`.
  - Empty content or a non-object tool input → `invalid_response`.
- **Errors**: matched by typed SDK class (abort/timeout/connection/401/403/429/5xx/other).
  - Messages keep only status; provider text/type/category are never echoed.
  - `retryable` is transport guidance; `VIPER_MODEL_MAX_RETRIES` defaults to 0 after review.
  - Abort → `cancelled`.
- **Streaming**: always streamed; the whole call and observers share a bounded deadline. With `onEvent`, it relays
  `text_delta` and `tool_call_delta` (with the tool call ID) and then `usage`, each awaited for
  backpressure. Deltas are provisional; only the final message becomes a decision.
- **Usage**: input = `input_tokens` + cache reads + cache writes; `source: 'provider'`.
