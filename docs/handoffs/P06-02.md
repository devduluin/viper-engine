## Behavior

GET events checks Bearer scope, path/query/header shape, signed event namespace/run/expiry,
future sequence and retained contiguous history. Ownership precedes expiry/state disclosure.
SSE id is opaque cursor; eventId/run+sequence dedup identity is separate. Header/query resume
must agree. Page cursors and tampered/foreign/future tokens fail; missing beginning gives 410
with fetch_snapshot. Snapshot cursor safely resumes after pruned prefix. Reconnect never executes.

Frames validate closed v1 schemas and configured bytes before output. Heartbeats have no ID.
Slow writes stop polling until drain; bounded timeouts/connections/queued bytes prevent an
unbounded subscriber queue. Auth is rechecked periodically. HTTP preClose terminates streams.
Signal scope is connection-only, never worker cancellation. Terminal tail drains then closes;
waiting runs follow until resumed/lifecycle cutoff. Live faults close; do not advance missing data.

Original approval pending status/revision and original input question survive later state changes.
Unknown outcomes remain OUTCOME_UNKNOWN with partial/cancelled semantics, never a success event.
All 13 durable event types are exercised across tests. Token deltas are not emitted; durable final
message/history are the recovery source. Preexisting incomplete event metadata fails closed to
snapshot fallback, not a guessed historical revision. Physical retention cleanup remains P08.
