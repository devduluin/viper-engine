## Implementation

- `src/contracts/api/`: modular portable JSON Schema 2020-12 and OpenAPI 3.1.1 data.
- 41 named request/response/content/error/approval/connection/cursor/event schemas; separate path
  modules for run operations and other resources. No validator/transport/framework SDK imports.
- 12 operations across 11 paths, inherited auth, required start-run idempotency header,
  clarification dedup/revision, comparison-only approval and bounded public snapshots.
- All 13 P01-03 durable event types have payload schemas and required correlation. Error and
  unknown tool outcomes remain distinct. Ephemeral deltas cannot claim durable sequence/ID.
- Server request/output shapes are closed; no body actor/app/tenant override, role/history,
  secret/stdio configuration, private MCP metadata or system-message serialization.
- Error codes map to HTTP status; revision and cursor-expiry errors require recovery metadata.
- Cursors have bounded opaque wire shape; authentication/codec/expiry checks remain P06.
- `scripts/export-openapi.mjs` plus `npm run api:export` produce artifacts/openapi/v1.json.
- Root exports add OPENAPI_DOCUMENT, API_SCHEMA_DOCUMENT/API_SCHEMA_ID, API_ERROR_STATUS/ApiErrorCode.
- [API guide](../api/README.md) owns dedup/replay/compatibility/projection semantics and P06 limits.

## Reuse and third-party fixture

- Consumes existing run/approval statuses, normalized messages/IDs and strict JSON cloning;
  no new legacy source copied and no P00 datasets/manifests rewritten.
- Official OpenAPI structural schema is pinned offline with hash and Apache-2.0 license.
  Provenance and Ajv dynamic-reference compatibility adaptation:
  [fixture notice](../../tests/fixtures/api/NOTICE.md).

## Integration boundaries and next work

P06 must implement HTTP auth, ownership-before-conflict, aggregate byte/JSON-depth limits,
message pairing, state/revision checks, trusted projections, cursor codec/lookup and SSE driver.
Schemas cannot enforce transactional state, sanitize arbitrary string contents, or prove cursor
ownership. The exporter does not start a server or access credentials/network/database.

P03 runtime work is owned by the coordinated Claude agent; none of its runtime/execution files
were modified here. P04-01 fresh persistence is dependency-ready following P01-03 review.
