## Boundaries for later agents

Plan is advisory user-role context, not authority, a verified fact, a completed step or an execution
graph. Steps cannot write or approve calls. Canonical user intent/history, ledger, approval binding
and existing input/output/repetition/deadline limits remain authoritative. No plan source copied
into canonical history/checkpoint/events/public output. Context budget includes its escaped bytes.
Plan revisions are immutable snapshots within a provider; host replacement may change later
evidence. Existing exact approved call still executes its persisted arguments once after restart.

No auto-ingestion from learning/recall. Model-generated proposal text must not become system policy,
approved tools, a host identity or an executable playbook. Scope JSON cannot create TrustedScope.
Binding mismatch omits the optional plan; malformed/unbranded scopes throw. Shared evidence count/
byte limits still apply when the host combines recall and plans. No persistent plan cursor promised.
