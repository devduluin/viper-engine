## Compatibility and decisions

Apply migration0011 for recall service; 0001..0010 bytes/checksums unchanged. Existing APIs/events/
runtime checkpoints stay compatible. Notes not enabled automatically. Context evidence not written
to messages, summary prefix or checkpoints. Scope comes from authentication and is checked on every
read/write; current source ownership and role also enforced by composite FK.

Notes are explicit selected user statements, labeled user_asserted. Assistant/tool outputs remain
untrusted history and are rejected as note sources. Correction uses a new user statement; deletion
removes active source pointer, not immutable history or historical audit source IDs. Notes text is
never duplicated into audit. Stale edits conflict; deleted tombstones cannot be revived.

Basic substring search is literal, bounded and owner-filtered, not vector/semantic ranking. Fixed
SQL timeout5s plus owner/recent indexes; host still owns pool/network deadlines. Notes up to8192
UTF8 bytes; result snippets512 chars; evidence16KiB; arbitrary provider evidence32KiB plus P07 budget.
