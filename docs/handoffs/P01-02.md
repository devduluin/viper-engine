## Semantics for downstream tasks

- These are normalized host contracts, not SDK/wire message types or a live MCP implementation.
- Model adapters map native output to final/tool_calls/needs_input. Decisions grant no approval,
  access, or execution authority; tool deltas are provisional and must not be dispatched.
- Complete tool-call/result pairing is required for model requests. Pending proposals remain
  valid as stored history but must be resolved before a request needing complete context.
- Model stream callbacks are awaited for backpressure. The final Promise contains the completed
  decision/result; truncated replies map to failure/output_limit rather than fake final success.
- Usage source and null counts preserve unavailable vs estimated vs provider counts. No price
  or provider/model policy is selected here. Run-level aggregate budgets stay runtime-owned.
- MCP references include connection/server/original name/definition version. Tuple keys isolate
  collisions and versions; the application maps them to model-facing aliases. A key is not a permit.
- Gateway implementations must look up connection ownership/availability on each operation.
  Binding helpers validate internal consistency and trusted context; they do not query auth/DB.
- Catalog annotations are untrusted hints. Input/output JSON Schemas are represented as JSON
  objects; actual schema compilation and business-argument validation belong to execution adapters.
- Resources are application-controlled and prompts user/application-selected. Content parsing
  does not fetch URIs or elevate prompt text into system authority.
- Text, image, audio, resource links, embedded text/blob resources, structured output and host-
  private metadata are kept separately. Structured data does not replace/drop text/media.
- `privateMeta` is host-only and must not automatically enter model context or public events.
  SDK adapters project wire metadata into this normalized surface; unknown content fails explicitly.
- Recoverable operation errors use typed result unions. Preflight errors throw; adapters/runtime
  still need a boundary for unexpected exceptions. Error messages are not authorization signals.
- Tool error does not guarantee no side effect. Unknown outcomes, cancellation after dispatch
  and timeout require execution evidence/reconciliation. Retryable is guidance, not retry policy.
- Protocol version is an opaque negotiated string, not pinned by these contracts. Subscription,
  sampling, elicitation and asynchronous MCP tasks are not enabled by baseline interfaces.
