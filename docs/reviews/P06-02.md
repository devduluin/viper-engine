# P06-02 integration review

Disposition: resolved; P06-02 DONE. Codex integration, 17 November 2026.
Self-review with regression evidence, not an independent external audit.

## Findings and fixes

1. **Internal events were not public DTOs.** Raw payloads omitted immutable revision/correlation/
   proposal/final facts and some step/tool events. Enrich producer metadata in existing atomic
   journal/store boundaries and hydrate only same-run immutable records. Explicit projection
   and schema checks exclude private SDK/MCP/system/connection data.
2. **Historical facts could drift.** Current run/approval state cannot represent an older event.
   Persist transition revision/attempt/proposal identity and reconstruct pending approval from
   immutable snapshot fields. Live approval/input tests replay unchanged history after resume.
3. **Approval notification preceded actionable state.** Proposal creation and pause were separate
   commits. Move actionable approval.required publication into the waiting transition transaction,
   remove duplicate generic notifications. Immediate HTTP accept succeeds from the received frame.
4. **Missing/expired histories risked silent gaps.** Owner checks, signed event namespace/expiry,
   safe future sequence and contiguous reads now gate replay. Missing beginning/interior gaps give
   410/fetch_snapshot. Cursor from a consistent snapshot can resume after a pruned prefix.
5. **Pruning all log rows broke append allocation.** Migration 0010 keeps the append guard aligned
   with run high water as well as retained max. A new event never resets to sequence 1 after prune.
6. **Transport lifetime/backpressure.** Raw reply bypasses ordinary serialization; validate frames
   before headers/writes, wait for drain before polling, bound initial/heartbeat/event writes,
   session counts, bytes and lifetime. preClose destroys active streams; disconnect is not run cancel.
7. **Long-lived auth and error handling.** Periodic same-principal reauthorization closes revoked
   sessions. Mid-stream faults close transport without injecting invalid error frames or acknowledging
   missing data. SQL reads are bounded/read-only and not held during network delivery.

## Evidence and boundaries

354 offline tests, 131 isolated PostgreSQL integrations, build/OpenAPI and compiled public factory
smokes PASS, zero failures/skips. Includes real HTTP sockets, actual SDK over scripted model fetch,
actual local MCP and all earlier worker OS-kill/fencing tests. Review cluster stopped afterward.

No live API key, app/dev/V4 DB, production migration, dependency install or evaluation dataset
change. Old metadata is not rewritten; incomplete legacy replay requires snapshot fallback.
Token deltas are not emitted; complete durable messages recover text. Retention deletion jobs,
deployment/proxy policy and operational metrics remain P08. P06-04 examples are next.
