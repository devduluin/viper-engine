# P07-01 review notes

Status: resolved; Codex implementation/self-review, 17 November 2026. R2.1.

1. **Prefix removal could break pairing or hide unresolved work.** Group only complete user turns
   outside pending batches. Protect current run, original clarification anchor, unknown outcome
   turn and recentTurns. Preserve reversed parallel results. Oversized required context stops.
2. **Compressed view cannot become execution state.** Canonical history remains unchanged. ID reuse,
   pending-call reconciliation, output/repetition budget, approval bindings and tool outcome use full
   durable evidence. Synthetic excerpts never append to history or introduce system messages.
3. **Summary integrity on resume.** Validate owner/run/conversation digest, anchor, safe boundary and
   deterministic excerpt before approved-call recovery, not only before the next model call.
   Damaged checkpoint blocks writes; explicit cancel can discard the context view and settle safely.
4. **Checkpoint lifetime.** Persist context and model-start/audit atomically under existing lease/CAS.
   Pin policy across worker restarts and clarification; do not reset current-run anchor to the newest
   input or a first assistant message. Legacy v1 checkpoints without context fields still load.
5. **TrustedScope is branded.** Hash explicit actor/app/tenant fields rather than a branded object
   with runtime symbol properties. Fingerprints are provenance checks, not authentication grants.
6. **Schema zero boundary.** Revision minimum=1 is wrong for report counters. omittedMessages=0
   caused HTTP serialization errors, surfacing as INTERNAL_ERROR and watch RECONNECT_LIMIT.
   Use nonnegative counters and retain a zero-omission contract regression plus existing headless tests.
7. **Fixture ownership.** Prior assistant history must belong to a completed prior run; user-only
   append cannot forge assistant messages. Fixture corrected; production append restrictions retained.
8. **Limits and disclosure.** Include tool schemas/instructions/output/framing reserve and full
   internal JSON bytes. Bound entire summary message even with escaped/Unicode content, not just
   raw excerpts. Publish report numbers/flags only; private excerpt/digest stays in runtime checkpoint.

400 offline cases and 145 isolated PostgreSQL cases PASS, including actual process kill and
approved-write restart. context:report gives deterministic raw before/after evidence; provider
quality/billing/comparison remain unmeasured. Prior migrations unchanged; no new dependency/table.
