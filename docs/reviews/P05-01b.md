## P1: streaming and observers were not bounded by the full deadline

As with the earlier Anthropic review, SDK request timeout did not bound every body/observer wait.
Fixed in `src/adapters/models/openai/gateway.ts`: P02 withDeadline covers iteration, final
assembly and awaited delta/usage callbacks. Use the earlier of the caller deadline and positive
host timeout (default 600000 ms), pass the child signal to the SDK and always abort on exit.
Timeout and caller cancellation remain distinct typed failures; no decision is returned late.

## P2: completion/usage/error metadata needed stricter normalization

- Unknown/missing/deprecated finish reasons, extra choices and disagreements between finish
  reason and function calls now fail closed. Truncation/filter/refusal guards remain intact.
- Usage is parsed through the safe-integer contract and total must equal prompt + completion.
  Absent usage remains unavailable, never fabricated as zero.
- Provider-controlled API error type is omitted from failure messages; status remains available.
- Bootstrap defaults SDK retries to zero, matching Anthropic/runtime attempt accounting.
- Compatible endpoint URLs reject embedded credentials/fragments; HTTPS/loopback rules remain.
