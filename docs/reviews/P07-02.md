# P07-02 review notes

Status: resolved, Codex implementation/self-review, 17 November 2026. R2.1.

1. **Generated answers are not facts.** Create/correct accepts only an existing owned user text
   statement, explicitly selected by host/user. No arbitrary text, role or verified flag; database
   composite FK rejects assistant/tool/cross-owner sources. Search labels generated history untrusted.
2. **Correction/deletion and audit.** Current notes reference immutable sources without text copies.
   Row-locked CAS and revision trigger give one winner; audit trigger records metadata atomically.
   Tombstone drops current pointer and is terminal. Audit/source history remains; note deletion is
   not global data erasure, and explicit history search can still find the original user statement.
3. **Fresh data versus durable execution.** New optional contextEvidence reads before every model
   call, under run control. User-only bounded data stays outside canonical history, summary digest
   and grant ledger. Correct/delete before next lookup changes evidence; already-issued data cannot
   be recalled. No cache or note mutation inferred from model responses or MCP output.
4. **Scope and query bounds.** All reads/writes filter actor/app/tenant, including history, source,
   audit and tombstone. Composite owner/source keys reinforce this. Literal parameterized substring
   search, result/snippet/UTF8 limits, 5s SQL timeout and owner/recent indexes bound the baseline.
5. **Context safety.** Evidence cannot supply system/assistant/tool role or override policy/scope/
   budgets. Canonical prefix validation and approved-call recovery remain unchanged. Complete model
   input includes evidence budget; invalid IDs/oversize data fail before model call. A hanging
   provider reaches run deadline without dispatch. Callback read failure cannot replay effects.
6. **Maintainability/compatibility.** Narrow contracts/service/evidence/store/query/command/row
   modules pass 300/180/60/10 gates. Migration0011 adds two tables, no earlier checksum changes.
   Public library/DTOs are host integration seams; HTTP routes/events and desktop scope unchanged.

417 offline cases (271 unit/146 contract), 154 isolated PostgreSQL cases, build/OpenAPI and compiled
public recall/context/client/HTTP/SSE/worker/engine smokes PASS; zero skips. Real SDK/MCP regression
shows correction/delete between calls without injecting text into system or execution checkpoint.
Current migration count11, engine tables18 plus ledger. Existing dataset hashes unchanged.

Literal matching/recency are not semantic ranking, large-volume search benchmarks, verified facts
or live answer-quality evidence. No .env/key/Workin/V4/app DB operation or deployment. Read
[guide](../scoped-recall.md), [handoff](../handoffs/P07-02.md) and [progress](../progress.md).
