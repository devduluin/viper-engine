# P06-04 review notes

Status: resolved. Codex implementation/self-review, 17 November 2026.
Scope: HTTP/SSE integration helper, examples and optional run usage. Not an independent reviewer claim.

## Findings resolved during implementation

1. **Additive response validation.** Closed server schemas reject future optional response fields.
   Client uses a separate relaxed response schema; original request schemas remain untouched.
   Same-role assistant variants overlap after relaxation: merge known properties into each anyOf
   variant so future fields are accepted without bypassing known toolCalls validation.
2. **Incomplete frame acknowledgement.** A split UTF8/CRLF or EOF must not move replay cursor.
   Incremental fatal decoder, bounded complete-frame parser, no inherited frame ID and no EOF
   dispatch of incomplete data. Ephemeral delta IDs are rejected and deltas cannot acknowledge.
3. **Observer lifetime versus run lifetime.** Each stream owns abort/reader cleanup; caller abort
   or break never invokes run cancel. Header deadline differs from idle deadline and stream lifetime.
   Teardown requests cancellation without awaiting an uncooperative stream's cancel promise;
   idle timeout must still reach the caller/reconnect policy. Regression covers a hanging cancel.
4. **Reconnect versus duplicate actions.** Only reads reconnect; mutation timeout/network errors
   are returned once. Sequence gaps/expired cursor use snapshot and a consistent highwater, not
   another start/tool/model call. Consumer checkpoints are handed out only with validated events.
5. **Final read retry.** Once terminal event was observed, a temporary snapshot fetch failure must
   retry the read without reopening a stream after the terminal cursor. Track terminal observation.
6. **Unknown usage.** Missing usage must not silently become zero. Count attempts, aggregate each
   token field only if all attempts report it; retain provider/estimate/mixed/unavailable provenance.
7. **Safe transport configuration.** Reject URL credentials/remote cleartext/path/query/fragment,
   unsafe dot path segments, invalid bearer, bad bounds/status/content type and wrong-run snapshots.
   Unknown upstream diagnostics become a symbolic client failure, not raw token/body/provider text.
8. **Combined-tree lint gate.** An additional Workin documentation seed script exceeded complexity
   in attendanceRow. Reused one calculated reason for its two fields, preserving behavior. Script
   was not executed and no service database was accessed. No other Workin integration edits.

Intermediate integration assertions were corrected to match existing engine semantics: all tool
failures mean failed; partial needs successful evidence alongside failure or an unknown outcome.
The model may summarize unknown tool evidence once; observation must not generate more attempts.
Assertions now check actual tool/write counts and unchanged model count across observer restart.
