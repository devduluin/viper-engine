# P05-04 integration review

Disposition: resolved; P05-04 DONE after combined workspace validation. Codex, 17 November 2026.
This is integration self-review with regression evidence, not an independent third-party audit.

## Findings and fixes

1. **Async schema bypass and compiler registry retention.** Ajv `$async` returns a Promise,
   which cannot be used as a boolean synchronous approval/dispatch check. Reject async schemas.
   A single shared Ajv instance also retains compiled schema registries after an external cache
   eviction. Use one compiler per cached schema and bounded capacity; `$id` cannot cross tools.
   Unit tests prove no coercion, local refs/formats, isolation, eviction and fail-closed errors.
2. **Chat Completions tool-result image shape.** Role tool accepts text, so using user image
   parts directly there would produce an invalid request. Keep correlated text tool messages,
   then attach labeled images as a user message after all tool results. Actual OpenAI SDK E2E
   verifies two result IDs/order, data URI and private metadata exclusion.
3. **Unsupported content after a completed tool.** A retained audio result previously reached
   context assembly as unsupported input and could throw instead of producing a terminal model
   failure. Preflight history content capabilities before the next model intent/call. Audio is
   retained, successful call stays succeeded, run fails honestly, tool is never replayed.
4. **Cold MCP connection cut short by request timeout.** The first full integration run had
   85/86 PASS: stdio cold startup exceeded the 5s request allowance despite a 20s connect limit.
   Pooled operations now allow connect acquisition plus SDK request limits; caller deadline,
   run limit and discovery/configure ceiling still apply. Full rerun: 86/86 PASS, including stdio.
5. **Routing and mutable boundaries.** Reacquire the pool by authenticated scope/connection on
   every operation, snapshot call/ref/arguments and read options before awaits, reject duplicate
   namespaces before model access. Cross-owner discovery causes no network; two live servers
   with identical tool names receive only their correctly bound call; post-model revoke blocks send.

## Evidence and remaining boundaries

328 offline tests, 86 isolated PostgreSQL integrations, build/OpenAPI export and compiled public
composition export smoke PASS. No skipped tests, actual live credentials or application DB.
Integration uses actual SDKs over scripted model fetch and local MCP HTTP/stdio; all earlier
OS process-kill persistence tests remain in the full integration suite.

The factory has no default allow policy, secret fallback, category registry or automatic retry.
Authorization/setup failures propagate and release the lease; HTTP/actionable mapping and host
backoff belong to P06. Provider-specific image formats still apply; no audio adapter/transcoder.
Live model compatibility, external OAuth service integration, operations and comparison scores
remain unmeasured. Source/function/complexity/dependency constraints remain enforced.
